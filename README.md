# Spot_Treating_AUMicb
Here you can find jupyter notebooks and related scripts which constitute the analysis of the HST/WFC3 transmission spectrum of AU Mic b presented in Waalkes et al. (2026). Notebooks are organized into sub-directories pertaining to different stages of the analysis (e.g., data processing, SED fitting, broadband light curve fitting, and spectroscopic light curve fitting).

Notebooks used to create the figures in the article have filenames that start with 'PLOT_'
